# K8 마이 드라이브 자동 전환 — 설치와 사용 (0.3.1)

마이 드라이브(커스텀) 모드의 세 항목을 주행 상황에 맞춰 자동으로 바꿉니다.

| 탭 | 항목 | 바꾸는 값 | 기준 |
|---|---|---|---|
| 서스펜션 | 서스펜션 | 에코 ↔ 스포츠 | 속도, 횡G(코너) |
| 핸들 | 스티어링 | 노멀 ↔ 스포츠 | 속도, 횡G(코너) |
| 엔진 | 파워트레인 | 에코 ↔ 스포츠 (가솔린 차는 노멀 ↔ 스포츠 선택) | 엑셀 페달 % |

순정 마이 드라이브 설정 화면이 쓰는 것과 같은 호출만 씁니다. **마이 드라이브 모드에서만** 동작합니다
(에코·스포츠·스마트 모드에서는 차가 모드별 값을 쓰므로 바뀌지 않습니다).
K8은 마이 드라이브와 스마트가 같은 모드 번호(6)로 들어옵니다. 그래서 모듈은 순정 설정 화면에서 마지막으로 고른 쪽
(마이 드라이브 / 스마트)을 기억해 구분합니다. 모르면 마이 드라이브로 봅니다.
감쇠력 퍼센트나 앞뒤 따로 조절은 차 구조상 불가능합니다.

## 대상

- 2021~ 기아 K8(GL3) **ECS(전자제어 서스펜션) 장착**, Gen5W 헤드유닛, **NEMESIS 설치됨**.
- 개발자 차량(K8 GL3 HEV, 국내형, 펌웨어 260902)에서만 확인했습니다. 다른 차종·트림은 번호가 다를 수 있고,
  그 경우 모듈이 "차가 따르지 않음"을 감지해 그 항목을 스스로 멈춥니다.

## 설치 — 서개모만 쓰는 경우 (가장 간단, 0.3.2부터)

서개모 모듈 두 개를 씁니다.
- **K8 마이 드라이브 엔진**(`k8-mydrive-engine-0.3.2.hsm`): 실제 전환을 하는 엔진. 설정 없음.
- **K8 마이 드라이브**(`k8-mydrive-0.3.2.hsm`): 설정·상태 카드. 설정을 바꿔도 재시작이 필요 없음.

1. 서개모 앱 → 모듈 추가 → USB에서 두 파일을 가져와 설치하고 둘 다 **켭니다**.
2. 엔진 모듈이 "재시작 필요"를 띄우면 **주차 상태에서** 헤드유닛을 재시작합니다. 처음 한 번만 필요합니다.
   (경우에 따라 시동 때 서개모가 마무리하면서 한 번 더 재시작을 요청할 수 있습니다.)
3. 재시작 뒤 엔진이 순정 앱(com.tcc.IpodUsbdeviceManager) 안에서 자동으로 뜹니다(서개모 앱 후킹 기능).
   NEMESIS 패키지와 헤드유닛 "K8 서스펜션" 앱은 필요 없습니다. 휴대폰 앱은 그대로 연결됩니다.
4. NEMESIS 패키지 k8ecs.damping이 이미 깔려 있으면 그쪽 엔진이 일하고 서개모 엔진은 쉽니다(엔진이 두 개 돌지 않음).

## 설치 — NEMESIS 패키지로 (헤드유닛 앱이 필요한 경우)

1. `k8ecs.damping-0.3.1.zip`(엔진)을 NEMESIS로 설치합니다.
   - USB(가장 쉬움): `k8ecs-USB설치-0.3.1.zip`의 압축을 풀어 나온 것(`NEMESIS.data`, `packages/`, `HSM/`)을
     USB 최상위에 그대로 넣고, 내비 화면이 뜬 뒤 꽂아서 확인 창에서 **예**를 누릅니다.
     USB에 원래 있던 `NEMESIS.data`는 덮어쓰게 되니 필요하면 먼저 보관하세요.
     이미 설치된 차를 새 버전으로 바꿀 때는 `NEMESIS.data`의 `type=install`을 `type=update`로 바꿉니다.
   - adb: `adb push k8ecs.damping-0.3.1.zip /data/local/tmp/` → `adb shell nemesis install /data/local/tmp/k8ecs.damping-0.3.1.zip`
     (업데이트는 `--update`).
2. 설치하면 엔진이 바로 시작되고, 헤드유닛에 **"K8 서스펜션"** 앱이 생깁니다(NEMESIS Manager → 내 패키지 → 실행).
3. 휴대폰 설정 앱(선택): `k8-ecs-phone-0.3.0.apk`(Android 13+). 헤드유닛과 블루투스 페어링된 상태에서 차량을 고르면 됩니다.

**엔진 패키지는 지우지 마세요.** 서개모 화면만 쓰더라도 실제 판단과 전환은 이 패키지가 합니다.

## 사용 (헤드유닛 앱)

1. **"자동 전환 켜기 (전체)"** 를 체크합니다. 기본값은 꺼짐입니다.
2. 위쪽 **서스펜션 / 핸들 / 엔진** 탭에서 쓰고 싶은 항목의 자동 전환을 켜고 기준을 정한 뒤 **저장**합니다.
3. 드라이브 모드를 **마이 드라이브**로 고르고 주행합니다. 정차·후진 중에는 보내지 않습니다.

**작동할 드라이브 모드 (0.4.4, 시험 기능)** — 엔진 탭의 "작동할 드라이브 모드"에서 마이 드라이브(기본) / 에코 / 노멀 중
하나를 고르면, 세 항목 모두 차가 **그 모드일 때만** 자동 전환합니다. 마이 드라이브를 쓰지 않는 차를 위한 선택입니다.
- 에코 = 모드 번호 2, 노멀 = 에코·스포츠·스마트가 아닌 모드(가솔린 노멀·컴포트).
- 앱은 드라이브 모드를 **읽기만** 합니다. 모드 자체(에코↔스포츠)는 바꿀 수 없고, 보내는 것은 마이 드라이브 항목 값입니다.
- 에코·노멀 모드에서 차가 이 값을 실제로 따르는지는 아직 확인하지 않았습니다. 응답 값만 바뀌고 주행 느낌이 그대로면 효과가 없는 것입니다.

### 서스펜션 탭

| 설정 | 기본 | 뜻 |
|---|---|---|
| 단단하게 바꿀 속도 | 100 km/h | 이 속도 이상이면 스포츠. 0이면 속도 규칙 끔 |
| 내려올 때 여유 | 15 km/h | 85 km/h 아래로 내려오면 에코로 복귀. **속도보다 작아야 합니다** |
| 코너 감지 기준 | 0.25g | 횡G가 0.3초 넘게 이 이상이면 스포츠. 0이면 코너 규칙 끔 |
| 코너 해제 기준 | 0.12g | 이 아래로 2.5초 유지되면 복귀 |
| 최소 유지 | 3초 | 한 번 바꾼 뒤 최소 유지 시간 |
| 분당 최대 전환 | 8회 | 항목마다 각각 적용 |

### 핸들 탭

서스펜션과 같은 방식(속도·코너)으로 스티어링 노멀 ↔ 스포츠를 바꿉니다. 기본: 100 km/h, 여유 15, 코너 0.30g / 0.15g, 유지 3초.

### 엔진 탭

| 설정 | 기본 | 뜻 |
|---|---|---|
| 노멀 ↔ 스포츠 (가솔린 차) | 꺼짐 | 끄면 에코(값 2), 켜면 노멀(값 0)로 돌아갑니다. 하이브리드 K8은 꺼 둡니다 |
| 스포츠로 바꿀 엑셀 | 60 % | 엑셀을 이만큼 이상 밟으면 바로 스포츠 |
| 되돌아갈 시간 | 5초 | 덜 밟은 채 이 시간이 지나면 에코(또는 노멀) |

- 노멀(값 0)은 하이브리드 실차에서 확인한 값이 아닙니다. 응답이 노멀(2)로 오지 않으면 엔진 자동 전환만 멈추고 더 보내지 않습니다.
  하이브리드에서 켜면 지금 에코 상태(응답 4)를 모르는 값으로 보고 엔진 자동만 멈춥니다.
- 엑셀 값은 헤드유닛이 받는 차량 값(`tm_hscan_service`의 `getAccelPdlVal`)으로, 끝까지 밟으면 100%입니다.

### 연동 옵션 (각각 켜고 끔)

| 탭 | 옵션 | 뜻 |
|---|---|---|
| 서스펜션 | 스포츠가 되면 엔진도 스포츠 | 서스펜션 규칙(속도·코너)이 스포츠를 원하는 동안 엔진도 스포츠 |
| 서스펜션 | 스포츠가 되면 핸들도 스포츠 | 같은 동안 핸들도 스포츠 |
| 엔진 | 스포츠가 되면 서스펜션도 스포츠 | 엑셀 규칙이 스포츠를 원하는 동안(유지 시간 포함) 서스펜션도 스포츠 |
| 엔진 | 스포츠가 되면 핸들도 스포츠 | 같은 동안 핸들도 스포츠 |

- 연동은 각 항목 **자기 규칙**이 원할 때만 이어집니다(연동끼리 서로 붙잡지 않음).
- 그 항목의 자동 전환을 꺼 두어도 연동만으로 움직입니다(연동이 풀리면 낮은 쪽으로 돌아감).

### 횡G

- **헤드유닛 GPS 모듈의 가속도 센서**로 직접 잽니다. 휴대폰은 필요 없습니다.
- 정차하면 영점을 잡고(바로 근사값으로 동작), 몇 번 가감속하면 센서 방향을 자동으로 배워 "완료"가 됩니다.
- 이상하면 "센서 보정 초기화"로 다시 배웁니다.

### 안전장치

- 항목마다 보낸 값과 차의 응답이 두 번 다르거나 응답이 없으면 **그 항목만 스스로 정지**합니다("정지됨" 표시). "정지 해제"로 다시 시작합니다.
- 내비가 쓰는 GPS 신호는 건드리지 않습니다(커널이 복제해 준 미사용 통로를 읽기 전용으로 엽니다). 엑셀 값도 읽기만 합니다.
- 모듈이 드라이브 모드 자체를 바꾸지는 않습니다.
- 서스펜션·핸들·파워트레인 설정은 주행 거동에 영향을 줍니다. **사용 책임은 운전자에게 있습니다.** 이상하면 앱에서 끄거나 NEMESIS에서 제거하세요.

## HMG-Seogaemo(서개모)에서 쓰기

서개모에는 카드 하나 **"K8 마이 드라이브"**(k8-mydrive)가 생깁니다. 서스펜션·핸들·엔진 설정과 연동 옵션이 모두 이 카드에 있습니다.
(서개모만으로는 안 됩니다: 서개모의 외부 모듈은 백그라운드 프로그램을 돌릴 수 없어서, 실제 판단과 전환은 NEMESIS 엔진 패키지가 합니다.)

1. 먼저 위 "설치"대로 NEMESIS 패키지 `k8ecs.damping` 0.3.1 이상을 설치합니다.
2. 같은 USB의 `HSM/k8-mydrive-0.3.2.hsm`을 서개모 앱의 모듈 추가 → USB에서 가져오기로 설치합니다.
3. 숫자 설정은 누르면 값 목록이 열리고, 목록에서 바로 고릅니다(예: 속도 30~160을 10단위, 엑셀 5~100%를 5단위).
   서개모의 +/- 버튼은 서개모 앱 자체 화면이라 길게 누르기를 넣을 수 없어서 이렇게 바꿨습니다.
4. 카드 맨 위 **탭**에서 서스펜션 / 핸들 / 엔진을 고르면 그 항목의 설정만 보입니다. 항목별 자동 전환과 기준, 연동 옵션을 정하고 카드를 **켭니다**.
   **끄면** 자동 전환 전체가 꺼집니다.
5. 카드 위쪽에서 상태(자동 전환 S/H/E — 마이 드라이브가 아니면 "WAIT (not My Drive)", 현재 서스/핸들/엔진과 전환 횟수, 속도/횡G/엑셀, 설정 반영 결과)를 봅니다. 도움말은 카드의 "도움말"에 있습니다.
   "rejected"면 값이 범위를 벗어난 것입니다(예: 여유가 속도보다 큼).
6. **"USB로 로그 저장"** 은 카드가 켜져 있을 때만 실행됩니다(서개모 규칙).

엔진이 다시 시작되면(재부팅·업데이트) 서개모에 저장된 설정을 다시 적용합니다.
카드를 업데이트한 뒤 화면이 예전 그대로면 서개모 앱을 닫았다가 다시 여세요(이전 화면을 기억함).
0.2.0의 카드 3개(k8-suspension, k8-steering, k8-engine)는 서개모에서 끄고 제거한 뒤 이 카드를 쓰세요.

## 기록(로그)

- `/data/nemesis/logs/k8ecs.damping/events.log` — 시작, 드라이브 모드·항목 변화, 송신(`SEND suspension firm (corner 312mg)`,
  `SEND powertrain sport (pedal 72%)` 등), 주행 중 10초마다 상태, 센서 학습 결과, 정지 사유. 2MB에서 `events.1.log`로 넘깁니다.
- `imu2.csv` — 주행 중 움직임 기록(속도, 가속도·자이로 원값, 횡G, 앞뒤 G, 엑셀). 4MB에서 `imu2.1.csv`로 넘깁니다.
- 위치 정보는 기록하지 않습니다.
- **USB로 받기**: USB(FAT32)를 꽂은 채 헤드유닛 "K8 서스펜션" 앱이나 서개모 서스펜션 카드에서 **"USB로 로그 저장"** 을 누릅니다.
  USB의 `K8ECS-LOG-날짜-시각` 폴더에 기록과 `info.txt`(펌웨어·모듈 버전)가 생깁니다. 헤드유닛에서는 읽기만 하고 USB에만 씁니다.
- adb로 읽기: `adb shell cat /data/nemesis/logs/k8ecs.damping/events.log`

## 제거

NEMESIS Manager → 내 패키지 → 제거, 또는 `adb shell nemesis uninstall k8ecs.damping`.
서개모 카드는 서개모 앱에서 제거합니다. 설정·학습값·기록은 `/data/nemesis/logs/k8ecs.damping/`에 남습니다(필요 없으면 삭제).
