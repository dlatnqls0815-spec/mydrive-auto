# K8 전자제어 서스펜션 감쇠력 앱 — 실현 가능성 조사

기준: 2026-11-15. 차량 접속 없이 PC 조사만 했다(차량 명령·송신 없음).
대상: 2021 Kia K8 GL3 HEV(전자제어 서스펜션 옵션), Gen5W 헤드유닛 + NEMESIS 1.16.4.

원하는 기능: ① 커스텀 퍼센트 제어 ② 속도 가변 ③ 코너 가변 ④ 앞뒤 따로.

> **2026-11-15 갱신: 사용자가 만도 ECS10(B안)은 불가능하다고 확인했다.** 남은 선택지는 A안(헤드유닛 모드 전환), C안(자작 하드웨어), 중단이다.

## 결론 먼저

- 네 가지를 전부 해 주는 **시판 제품이 이미 있다**: 만도 **SDC ECS10**(약 43~45만 원, 전용 휴대폰 앱).
  다만 **K8은 공식 지원 차종 목록에 없다.** 지원 여부를 만도 총판에 물어보는 것이 첫 단계다(비용 0, 차에 갈 필요 없음).
- 헤드유닛(NEMESIS)만으로는 **퍼센트 제어가 안 된다.** 헤드유닛이 아는 감쇠 상태는 자동/소프트/하드 3가지뿐이고,
  감쇠력 숫자를 정하는 설정 통로는 발견되지 않았다.
- 직접 만드는 하드웨어(댐퍼 배선 사이 ESP32 컨트롤러)는 이론상 네 가지가 다 되지만,
  순정 ECU의 실시간 제어를 없애는 일이라 **승차감·안전이 순정보다 나빠질 가능성이 크고** 고장 코드·보증 위험이 가장 크다. 권하지 않는다.

## 1. K8 ECS 구조

확인된 것
- 감쇠력은 **ECS ECU**가 정한다. 차체·바퀴 움직임 센서, 차속, 조향각, 드라이브 모드(섀시 CAN), 전방 카메라·내비 정보(프리뷰 기능)를 받아
  댐퍼마다 달린 솔레노이드 밸브에 흘리는 **전류**를 수 ms 단위로 바꾼다. 휴대폰이나 헤드유닛은 이 계산에 끼지 않는다.
- 이런 연속 가변 댐퍼는 원래 **바퀴별 독립 제어**다(코너에서 바깥쪽만 단단하게 하는 식). 운전자에게는 모드 2~3개만 보일 뿐이다.
- K8 드라이브 모드: 컴포트·에코·스포츠·스마트·커스텀(기아 취급설명서). 스포츠·커스텀은 재시동 시 유지되지 않는다.

확인 못 한 것(추정으로 채우지 않음)
- K8 GL3 ECS의 **공급사**(만도인지 여부), 솔레노이드 전류 범위·PWM 주파수, 전류 0일 때 단단해지는지 부드러워지는지.
  참고로 타사 동급 밸브는 0.3~1.6A, PWM 0.5~2kHz 수준이다(Solero 자료, K8 값 아님).
- K8 커스텀 모드 화면에 **서스펜션 항목**이 따로 있는지. 같은 계열 현대 설명서에는 파워트레인/스티어링/서스펜션(스마트·노멀·스포츠)이 나뉘어 있다.
  → 사용자가 설정 화면을 한 번 보면 바로 확인된다.

### A. 헤드유닛 경로

기존 분석 자료(`k8-ambient-sync/private/oem-sml-analysis`, 헤드유닛 프레임워크 디스어셈블리)를 읽기 전용으로 확인했다.

- **읽기는 있다**: `IBCMService.getEcsStatus()`, `BCMDriveListener.onEcsStatusChanged(actHeight, dampingMode, sysNA, ecsEef, levelChgNA, reqHeight, reqDamping, lifting, lowerint)`.
  `DampingMode`·`ReqDampingState` 값은 **AUTO(0) / SOFT(1) / HARD(2)** 세 가지뿐이다. 퍼센트나 전류 값은 없다.
- **감쇠력을 정하는 쓰기 함수는 없다.** BCM 서비스에는 ECS 설정 함수가 없고, 모드 쪽에
  `ISystemService.setIndividualDriveMode(int,int)`, `requestDriveCustomMode2(byte[])`, `requestNewMyDriveMode(byte[])`, `setAdditionalDriveMode(byte[])`가 있을 뿐이다.
  이 프레임워크는 여러 차종 공용(N 모드 항목 포함)이라 **K8에서 실제로 동작하는지는 모른다.**
- 지금까지 수집한 헤드유닛 로그에는 ECS·감쇠 관련 줄이 없다(수집 필터가 조명 위주였던 영향일 수 있음).
- 따라서 이 경로의 최대치는 "속도·코너에 따라 서스펜션 **모드**(노멀↔스포츠)를 자동으로 바꾸는 것"이다.
  그것도 헤드유닛에서 마이컴으로 **명령을 보내는 일**(Binder 송신)이라 사용자 승인과 정차 시험이 필요하고,
  커스텀 모드에 서스펜션 항목이 없으면 스포츠 모드 전체(가속 반응·핸들 무게)가 같이 바뀐다.

### B. 만도 SDC ECS10 (시판)

- 만도(순정 ECS 제조사)가 만든 튜닝 모듈. 담뱃갑 크기, 스티어링 칼럼 쪽 **CAN 커넥터에 끼워 넣는 방식**(가공 없음) + ACC 퓨즈 전원, 장착 30분~1시간.
  즉 댐퍼 배선을 건드리지 않고, 순정 ECS ECU가 계속 제어하되 그 기준값을 바꾸는 방식으로 보인다(내부 동작은 비공개).
- 앱(Android/iOS, 개발자 한라홀딩스, 2025-09 업데이트, 블루투스 연결·휴대폰 GPS 사용):
  - MODE: 컴포트/스포츠/스포츠+ 와 커스텀 3개
  - BASIC: RIDE(앞뒤 출렁임 감도), HANDLING(코너 롤 감도) 강도 조절
  - ADVANCED: **속도별**로 RIDE·HANDLING 값을 지정(구간 사이는 연속으로 변함)
  - **앞·뒤 독립** 설정, 앱에서 OFF 하면 순정으로 복귀, 시동을 꺼도 설정 유지
- 사용자 후기(스팅어): 순정은 대략 3~7 범위만 쓰는데 0~10 전체를 쓸 수 있고, 0은 심하게 출렁이고 100은 "스프링 없는 차" 같다고 한다(개인 후기).
  판매처는 "순정은 60%까지만 쓴다"고 광고한다(검증 안 된 홍보 문구).
- **문제: K8이 지원 목록에 없다.** 앱 지원 차종은 G70, G80(DH/RG3), G90, K9, 스팅어, GV80, 벨로스터N, i30N, 코나N, 아반떼N, GV60, EV6 GT, EV9 GT.
  판매 옵션도 A(DH/IK/CK)·B(K9)·C(JSN)·D(RG3/JX1) 타입뿐이다. K8 ECS가 만도 제품이 아니거나, 커넥터·CAN 구성이 다르면 쓸 수 없다.
- 앱 리뷰에 "자동 연결이 시동마다 풀린다", "커스텀 값 찾기가 어렵다"는 불만이 있다.

### C. 자작 댐퍼 배선 컨트롤러

ECU와 댐퍼 사이 배선에 ESP32 장치를 넣어 솔레노이드 전류를 직접 정하는 방식.

필요한 것
- ESP32(WROOM-32D로 충분), 전류 제어 드라이버 4채널(전류 감지 포함), IMU(예: MPU-6050), 12V 차량용 전원부·보호 회로
- ECU 쪽에 물릴 **가짜 부하**(없으면 ECU가 단선 고장 코드를 띄움)
- 전원이 죽으면 ECU↔댐퍼를 그대로 다시 잇는 **바이패스 릴레이**(실패 시 순정 복귀의 핵심)
- 순정 커넥터와 같은 규격의 암수 커넥터 4조, 방수 케이스(댐퍼 근처는 물·진동·열 환경)
- 사전 조사: 정비 배선도, 댐퍼 커넥터 핀, **실차 전류 파형 실측**(오실로스코프·전류 프로브)

솔직한 평가
- 순정 ECU는 바퀴별로 수 ms마다 전류를 바꾼다. 자작 장치가 고정 퍼센트를 넣으면 그 제어가 **사라진다.**
  "퍼센트는 마음대로"가 되지만 요철·급제동·긴급 회피에서의 거동은 순정보다 나빠질 수 있다.
- ECU는 자기가 낸 전류와 실제 거동이 다르다는 것을 알아챌 수 있고, 경고등·고장 코드·ECS 비상 모드로 갈 수 있다.
- 코일 과전류로 밸브를 태우면 댐퍼 교체다(전자제어 댐퍼는 개당 수십만 원대).
- 네 바퀴 근처 배선 작업이 필요해 차에 여러 번, 리프트가 있는 곳에 가야 한다.
- 개발 기간은 몇 주가 아니라 몇 달로 봐야 한다.

### D. CAN 직접 송신 자작

ECS10이 하는 일을 직접 흉내 내는 방식. 섀시 CAN의 어떤 메시지를 어떻게 바꾸는지 공개 자료가 없고,
섀시 CAN에는 제동·조향·ESC가 같이 물려 있다. 잘못된 프레임 하나가 주행 중 경고등이나 제어 이상으로 이어질 수 있어 **권하지 않는다.**

## 3. 속도·코너 입력

- 속도: 차량 중계의 `TEL <kmh> <park> <rev> <mode>`(RFCOMM, 이미 동작) 또는 휴대폰 GPS(1초 단위, 터널에서 끊김).
- 코너: 휴대폰 가속도계의 횡가속도(거치 방향 보정·저역 필터 필요), 또는 자이로 요레이트 × 속도.
  휴대폰이 거치대에서 흔들리면 오차가 크다. 자작 경로라면 차체에 고정한 IMU가 낫다.
- 지연: 휴대폰 센서 → 블루투스 → 장치까지 50~150ms. 코너 진입 롤 억제에는 쓸 만하지만 요철 대응에는 느리다.
  어느 경로든 "휴대폰이 실시간 제어"가 아니라 **"휴대폰은 설정만, 실시간 판단은 차 쪽 장치"**가 맞는 구조다(ECS10도 그렇다).

## 4. 안전·보증·검사

- 감쇠력은 제동 거리, 급차선 변경 안정성, ESC 개입 시점에 영향을 준다. 너무 부드러우면 고속에서 출렁이고, 너무 단단하면 요철에서 접지가 떨어진다.
- 실패 시 원칙: 장치 전원 끊김·통신 끊김·휴대폰 꺼짐 → **자동으로 순정 상태**. 값 변경은 천천히, 범위는 처음에 좁게.
- 경고등·고장 코드: B는 제조사 제품이라 가능성이 낮지만 K8 미지원 상태에서 억지로 달면 알 수 없다. C·D는 가능성이 높다.
- 보증: 서스펜션·ECS 관련 고장에서 사제 장치가 발견되면 보증 수리를 거절당할 수 있다. B는 떼면 순정으로 돌아간다.
- 정기검사: 경고등이 켜져 있으면 문제가 된다. 전자 모듈 추가가 튜닝 승인 대상인지는 확인하지 못했다(장착점·교통안전공단에 확인 필요).

## 5. 추천 순서

1. **만도 총판 또는 판매점에 문의**: "2021 K8 GL3 하이브리드, 전자제어 서스펜션 옵션 차량에 ECS10 장착 가능한가, 어느 타입인가."
   가능하다면 이것이 네 기능을 가장 싸고 안전하게 얻는 길이고, 앱을 새로 만들 이유가 거의 없다.
2. 안 된다면 선택지는 셋이다.
   - A안: 헤드유닛으로 서스펜션 **모드** 자동 전환(2~3단계, 퍼센트·앞뒤 불가). 송신 시험은 승인 후 정차 상태에서.
   - C안: 자작 하드웨어(위험·비용·시간 큼).
   - 그만두기.
3. 다음에 차에 갈 일이 있을 때 **묶어서 볼 것**(모두 읽기 전용):
   - 드라이브 모드 → 커스텀 설정 화면에 "서스펜션" 항목이 있는지(사진 한 장)
   - 모드를 바꾸는 동안 `BCMService`·`SystemService` 로그에 ECS 상태 줄이 찍히는지
   - (C안을 볼 경우만) 댐퍼 상단 커넥터와 부품 라벨 사진 → 공급사·품번 확인
