# K8 마이 드라이브

맨 위 **탭**에서 서스펜션 / 핸들 / 엔진을 고르면 그 항목의 설정만 보입니다.

- 마이 드라이브(커스텀) 모드로 주행 중일 때만 동작합니다. 아니면 상태에 "WAIT (not My Drive)"가 보입니다.
- 숫자 설정은 누르면 값 목록이 열립니다.
- 차가 따르지 않으면 그 항목은 스스로 멈춥니다.
- 실제 전환은 "K8 마이 드라이브 엔진" 모듈(또는 NEMESIS 패키지 k8ecs.damping)이 합니다. 엔진 모듈을 켜고 헤드유닛을 한 번 재시작하세요.
- 이 카드의 설정을 바꿔도 재시작은 필요 없습니다.
- 연동: 한 항목이 자기 규칙으로 스포츠가 되면, 켜 둔 다른 항목도 스포츠가 됩니다.
- 앰비언트 스포츠 빨강: 스포츠 모드이거나 마이 드라이브 항목 중 하나라도 스포츠면 차량 앰비언트를 빨강으로 바꿉니다.
- 스포츠 종료 후 복귀 대기: 클러스터·앰비언트가 원래 값으로 돌아가기까지 0~5초로 설정합니다. 기본은 0초이며 송신 간격은 최소 3초입니다.
- 클러스터 스포츠 테마: 스포츠 모드이거나 마이 드라이브 항목 중 하나라도 스포츠면 고른 테마(A~D)로 바꾸고, 끝나면 바로 원래 테마로 돌려놓습니다.
- "USB로 로그 저장"은 카드가 켜져 있을 때만 실행됩니다.
- 사용 책임은 운전자에게 있습니다.
